# Ontario Competitive Bid Snapshot — Release Preflight

**Purpose:** one-page quality gate for a reviewable GrainBids Competitive Bid Snapshot. Complete before sharing a draft with a prospect or customer.

**Boundary:** Ontario first; public or customer-authorized data only. No employer-confidential information. No outreach, sending, publishing, or price recommendation is authorized by this checklist.

## 1. Identity and scope

- [ ] Region is stated and remains Ontario-first.
- [ ] “Data captured through” includes date, time, and timezone.
- [ ] Each commodity is named exactly as reported.
- [ ] Freight treatment is explicit: excluded, included, or separately modelled.
- [ ] The report says posted bids, not executable quotes or recommendations.

## 2. Comparable-row checks

For every row used in a range, rank, or change statement:

- [ ] Buyer/facility and Ontario location are recorded.
- [ ] Delivery period is stated.
- [ ] Futures contract is stated when the source provides one; otherwise it is marked unavailable.
- [ ] Cash price and basis are never substituted for one another.
- [ ] Currency and unit are explicit: **CAD/MT** or **CAD/bu**.
- [ ] Grade, premium/discount, and special terms are preserved where posted.
- [ ] Capture timestamp and public URL/source ID are present.
- [ ] A row with a different delivery period, grade, futures contract, currency, or unit is not described as directly comparable.

## 3. Change logic

- [ ] Every stated movement uses an exact match on commodity, buyer/facility, delivery period, futures contract, and unit.
- [ ] If no exact match exists, the report says so rather than inferring a change.
- [ ] Contract rolls and changed delivery buckets are disclosed as non-comparable.

## 4. Source attribution and freshness

- [ ] Every numerical claim maps to a source URL or source ID.
- [ ] Source-health table lists last observed time and age at report time.
- [ ] Stale, unavailable, or incomplete sources are disclosed.
- [ ] Any conversion keeps the original figure and clearly states the method; no unlabelled conversions.

## 5. Safety and readability

- [ ] No employer, customer, login-gated, or otherwise confidential data appears.
- [ ] No advice to buy, sell, hedge, store, or contract grain appears.
- [ ] Limitations cover verification of current price, grade, delivery period, terms, and freight.
- [ ] Tables remain readable on a standard page or are split by commodity.
- [ ] A reviewer can trace every executive finding to a row and source.
